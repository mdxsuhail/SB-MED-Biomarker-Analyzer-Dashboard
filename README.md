# SB-MED01 Biomarker Analyzer Dashboard

A React dashboard prototype for displaying biomarker-style readings, trend charts and status labels. The current implementation uses generated sample data in the frontend; it is not connected to a medical analyser or validated clinical data source.

> **Educational UI prototype · Not a medical device · Not for diagnosis or treatment decisions**

## Overview
The dashboard presents five example measurements: Troponin, Glucose, HbA1c, Creatinine and ALT. The frontend includes summary cards, time-series visualisations and a recent-reading table. Status labels are generated by threshold rules in services/dataService.ts.

## Features in the current code
- React and TypeScript single-page interface
- Sample biomarker readings generated in the frontend
- 24-hour-style chart data generated for visualisation
- Normal / Elevated / Critical status classification
- Biomarker units and threshold rules
- Separate Python data-processing example in scripts/process_biomarkers.py

## Run locally
Prerequisite: Node.js and npm.

```bash
git clone https://github.com/mdxsuhail/SB-MED-Biomarker-Analyzer-Dashboard.git
cd SB-MED-Biomarker-Analyzer-Dashboard
npm install
npm run dev
```

Open the local URL printed by Vite.

Create a production build with npm run build and preview it with npm run preview.

## Demo classification thresholds
| Measurement | Unit | Elevated from | Critical from |
|---|---:|---:|---:|
| Troponin | ng/mL | 0.05 | 0.40 |
| Glucose | mg/dL | 141 | 200 |
| HbA1c | % | 5.7 | 6.5 |
| Creatinine | mg/dL | 1.4 | 2.0 |
| ALT | U/L | 56 | 101 |

These values are implementation constants for a UI demonstration. They are not a substitute for laboratory reference intervals, assay-specific validation or clinician interpretation.

## Python example
The separate script reads a local sensor_readings.csv file and processes heart_rate and oxygen_level columns. It fills missing values with column medians, assigns a simple status and can export a JSON summary.

```bash
pip install pandas numpy scikit-learn
python scripts/process_biomarkers.py
```

The CSV input file must contain the columns expected by the script. This utility is not currently a live backend for the React dashboard.

## Current limitations
- Frontend readings and chart history are generated sample data, not live patient measurements.
- The Python utility is separate from the frontend application.
- There is no validated diagnostic algorithm, clinical workflow, patient database or medical-device certification.
- Thresholds and generated data are for software demonstration only.
